# Yv-Me ROI Calculator

Customized ROI and programme economics calculator for the EasePal Care
Yobe State 12-month pilot.

## Core Budget Model

- CHEWs / Nurses: 100
- Beneficiaries: 500
- Average beneficiaries per CHEW: 5
- Pilot duration: 12 months
- Programme budget: NGN 407,343,531
- Location: Yobe State, Nigeria

## Purpose

The Yv-Me ROI Calculator converts the approved programme budget into
an interactive financial model for:

- Programme cost analysis
- Cost per CHEW
- Cost per beneficiary
- Monthly operating cost
- Annual operating cost
- Staffing economics
- Service delivery economics
- Revenue scenarios
- Partnership ROI
- Break-even analysis
- Scaling scenarios
- Private-sector partnership analysis

## Budget Structure

1. Objective 1 — Training and Deployment
2. Objective 2 — Community-Based Care Delivery
3. Objective 3 — Advocacy and Technical Support
4. Objective 4 — Health Governance and Public Awareness
5. Communications and M&E
6. Equipment
7. Personnel
8. Management / Indirect Costs
